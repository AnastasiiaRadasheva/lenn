## Deploy (GitHub Pages)

1. Loo uus **public** repositoorium GitHubis
2. Laadi üles kõik failid (sh pildid)
3. `Settings → Pages → Deploy from branch → main → Save`
4. ~1 min pärast leht on üleval: `https://[kasutajanimi].github.io/[repo-nimi]`
